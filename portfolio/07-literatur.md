# 7 Literatur

Zitiert wird im Text als (Autor Jahr) bzw. (Kurzname Jahr). Projektinterne Quellen (ADRs, API-Design, Protokolle, KI-Logs) werden mit Dateiname oder Issue-Nummer im Docs-Repository angegeben und hier nicht wiederholt. Jedes Kapitel ergänzt seine Quellen alphabetisch.

- **Fielding 2000:** Fielding, R. T. (2000): *Architectural Styles and the Design of Network-based Software Architectures.* Dissertation, University of California, Irvine. Kapitel 5: Representational State Transfer (REST).
- **GraphQL Specification 2021:** GraphQL Foundation (2021): *GraphQL Specification, October 2021 Edition.* https://spec.graphql.org/October2021/
- **MACH Alliance:** MACH Alliance: *MACH: Microservices-based, API-first, Cloud-native SaaS and Headless.* https://machalliance.org
- **PostgreSQL Documentation:** PostgreSQL Global Development Group: *PostgreSQL Documentation, SELECT, The Locking Clause* (FOR UPDATE, SKIP LOCKED). https://www.postgresql.org/docs/current/sql-select.html
- **RFC 6750:** Jones, M.; Hardt, D. (2012): *The OAuth 2.0 Authorization Framework: Bearer Token Usage.* RFC 6750, IETF.
- **RFC 9110:** Fielding, R.; Nottingham, M.; Reschke, J. (2022): *HTTP Semantics.* RFC 9110, IETF.
- **Spring Framework Documentation:** Spring: *Data Access, Transaction Management, Transaction Propagation.* https://docs.spring.io/spring-framework/reference/data-access/transaction/declarative/tx-propagation.html
- **Twelve Data 2026:** Twelve Data: *Are the prices adjusted?* Support-Artikel. https://support.twelvedata.com/en/articles/5179064-are-the-prices-adjusted (abgerufen am 01.11.2026)
